soal

Anda harus membuat sebuah lunches variabel dan menetapkannya array kosong yang akan digunakan untuk menyimpan item makan siang.

Anda harus membuat fungsi addLunchToEnd itu mengambil array sebagai argumen pertama dan string sebagai argumen kedua.
Fungsi tersebut harus:
Tambahkan string ke akhir array. Catat stringnya [Lunch Item] added to the end of the lunch menu. ke konsol, di mana [Lunch Item] apakah string diteruskan ke fungsi.
Kembalikan array yang diperbarui.

Anda harus membuat fungsi addLunchToStart itu mengambil array sebagai argumen pertama dan string sebagai argumen kedua. Fungsi tersebut harus:
Tambahkan string ke awal array. Catat stringnya [Lunch Item] added to the start of the lunch menu. ke konsol, di mana [Lunch Item] apakah string diteruskan ke fungsi.
Kembalikan array yang diperbarui.

Anda harus membuat fungsi removeLastLunch itu mengambil array sebagai argumennya. Fungsi tersebut harus:
Hapus elemen terakhir dari array. Jika penghapusan berhasil, catat stringnya [Lunch Item] removed from the end of the lunch menu. ke konsol, di mana [Lunch Item] apakah elemen dihapus dari array.
Jika array kosong, catat stringnya "No lunches to remove." ke konsol.
Kembalikan array yang diperbarui.

Anda harus membuat fungsi removeFirstLunch itu mengambil array sebagai argumennya. Fungsi tersebut harus:
Hapus elemen pertama dari array.
Jika penghapusan berhasil, catat stringnya [Lunch Item] removed from the start of the lunch menu. ke konsol, di mana [Lunch Item] apakah elemen dihapus dari array.
Jika array kosong, catat stringnya "No lunches to remove." ke konsol.
Kembalikan array yang diperbarui.

Anda harus membuat fungsi getRandomLunch itu mengambil array sebagai argumennya. Fungsi tersebut harus:
Pilih elemen acak dari array.
Jika berhasil, catat stringnya Randomly selected lunch:
[Lunch Item] ke konsol, di mana [Lunch Item] adalah elemen acak dalam array.
Jika array kosong, catat stringnya "No lunches available." ke konsol.

Anda harus membuat fungsi showLunchMenu yang mengambil array sebagai argumennya dan:
Jika ada elemen dalam array, log string Menu items:
[Lunch Item], [Lunch Item]... ke konsol, di mana masing-masing [Lunch item] adalah salah satu elemen dalam array, secara berurutan.
Jika array kosong, log string "The menu is empty." ke konsol.
